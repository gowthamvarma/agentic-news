# Documentation Guide

This directory contains resources, guides, official documentation, source code references, and sample implementations for building AI agents with Google Agent Development Kit (ADK).

---

## Directory Overview

| Directory / File | Description |
| :--- | :--- |
| [`agents/`](./agents/) | **Agent Design Best Practices**: In-depth guidance, patterns, and best practices for architecting and building robust AI agents (including behaviors, memory, state management, skills, and tools). |
| [`google-adk/`](./google-adk/) | **Google ADK Documentation**: A complete local extract from [adk.dev](https://adk.dev/) covering architecture, runtimes, sessions, tools, live workflows, guardrails, and integrations. |
| [`references/adk-python/`](./references/adk-python/) | **ADK Source Code**: Complete source code repository of the Python Agent Development Kit (ADK) for inspecting underlying implementation details and APIs. |
| [`references/adk-samples/`](./references/adk-samples/) | **Sample Code & Examples**: Working sample projects, recipes, and end-to-end demonstrations illustrating how ADK is used across different agent architectures. |
| [`ai-builder-cup.md`](./ai-builder-cup.md) | **Hackathon Reference**: Summary of the Google Cloud AI Builder Cup guidelines, judging criteria, technical constraints, and the selected *Media, Content & Digital Experiences* theme. |
| [`news-analyser.md`](./news-analyser.md) | **Project Specification**: Concept, multi-agent architecture, Google ADK integration, and deep insights roadmap for the News Analyser application. |
| [`best-agents-architecture-guide.md`](./best-agents-architecture-guide.md) | **Master Agent Architecture Guide**: Comprehensive blueprint for building best-in-class agents using Google ADK 2.0 (Graph & Dynamic Workflows, Collaborative patterns, Skills, Callbacks, Plugins, Pydantic schemas, and Evidence Ledger). |

---

## How to Use These Resources

1. **Master Architecture Blueprint**:
   - Start with [`best-agents-architecture-guide.md`](./best-agents-architecture-guide.md) for the end-to-end blueprint on architecting world-class agents tailored to the News Analyser application.

2. **Learning Agent Concepts & Best Practices**:
   - Refer to [`agents/`](./agents/) when designing agent architecture, tool abstractions, memory pipelines, and stateful interactions.

3. **Google ADK Reference & Features**:
   - Consult [`google-adk/`](./google-adk/) for official ADK guides, configurations, APIs, and runtime specs extracted from [adk.dev](https://adk.dev/).

4. **Code Implementation & Samples**:
   - Inspect [`references/adk-python/`](./references/adk-python/) for internal class definitions, interfaces, and core library code.
   - Explore [`references/adk-samples/`](./references/adk-samples/) for runnable code snippets and implementation examples.
