# Documentation Guide

This directory contains resources, guides, official documentation, source code references, and sample implementations for building AI agents with Google Agent Development Kit (ADK).

---

## Directory Overview

| Directory / File | Description |
| :--- | :--- |
| [`agents/`](file:///C:/tools/github/agentic-news/docs/agents) | **Agent Design Best Practices**: In-depth guidance, patterns, and best practices for architecting and building robust AI agents (including behaviors, memory, state management, skills, and tools). |
| [`google-adk/`](file:///C:/tools/github/agentic-news/docs/google-adk) | **Google ADK Documentation**: A complete local extract from [adk.dev](https://adk.dev/) covering architecture, runtimes, sessions, tools, live workflows, guardrails, and integrations. |
| [`references/adk-python/`](file:///C:/tools/github/agentic-news/docs/references/adk-python) | **ADK Source Code**: Complete source code repository of the Python Agent Development Kit (ADK) for inspecting underlying implementation details and APIs. |
| [`references/adk-samples/`](file:///C:/tools/github/agentic-news/docs/references/adk-samples) | **Sample Code & Examples**: Working sample projects, recipes, and end-to-end demonstrations illustrating how ADK is used across different agent architectures. |
| [`ai-builder-cup.md`](file:///C:/tools/github/agentic-news/docs/ai-builder-cup.md) | **Hackathon Reference**: Summary of the Google Cloud AI Builder Cup guidelines, judging criteria, technical constraints, and the selected *Media, Content & Digital Experiences* theme. |

## How to Use These Resources

1. **Learning Agent Concepts & Best Practices**:
   - Refer to [`docs/agents/`](file:///C:/tools/github/agentic-news/docs/agents) when designing agent architecture, tool abstractions, memory pipelines, and stateful interactions.

2. **Google ADK Reference & Features**:
   - Consult [`docs/google-adk/`](file:///C:/tools/github/agentic-news/docs/google-adk) for official ADK guides, configurations, APIs, and runtime specs extracted from [adk.dev](https://adk.dev/).

3. **Code Implementation & Samples**:
   - Inspect [`docs/references/adk-python/`](file:///C:/tools/github/agentic-news/docs/references/adk-python) for internal class definitions, interfaces, and core library code.
   - Explore [`docs/references/adk-samples/`](file:///C:/tools/github/agentic-news/docs/references/adk-samples) for runnable code snippets and implementation examples.
