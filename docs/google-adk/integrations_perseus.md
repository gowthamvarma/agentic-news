# Perseus Context integration for ADK[¶](#perseus-context-integration-for-adk "Permanent link")

Supported in ADKPython

The [`adk-perseus-context`](https://github.com/Perseus-Computing-LLC/adk-perseus-context) integration injects a deterministically compiled context into your ADK agent's system instruction. It is powered by Perseus, an open-source context compiler: Perseus resolves directives like `@file`, `@search`, and `@memory` into one byte-stable context string at inference time, with no retrieval index, no embeddings, and no extra LLM round-trip. Everything runs locally.

Perseus is a context compiler, not a memory or RAG backend. For persistent cross-session memory, pair it with its companion, [Perseus Vault](/integrations/perseus-vault/).

## Use cases[¶](#use-cases "Permanent link")

-   **Deterministic context assembly**: The same inputs always compile to the same context, with byte-identical builds and no per-query retrieval variance
-   **Workspace-aware agents**: Resolve `@file`, `@include`, `@search`, and `@memory` directives so the agent sees current project files and state
-   **Index-free, local context**: No vector store, no embeddings, no cloud. The context is compiled on the machine that runs the agent
-   **Full coverage at a fixed size**: Pull in exactly the context you declared, rather than a top-k slice

## Prerequisites[¶](#prerequisites "Permanent link")

-   Python 3.10+
-   `google-adk>=1.14.0`
-   `perseus-ctx>=1.0.10` (installed automatically with `adk-perseus-context`)

## Installation[¶](#installation "Permanent link")

`[](#__codelineno-0-1)pip install adk-perseus-context`

## Use with agent[¶](#use-with-agent "Permanent link")

There are two ways to inject a compiled Perseus context. Use the plugin for a context shared across every agent in a `Runner`, or the callback for a single agent. `source` is a path to a `.perseus` file or an inline string starting with `@perseus`.

### Runner-wide (plugin)[¶](#runner-wide-plugin "Permanent link")

`[](#__codelineno-1-1)from adk_perseus_context import PerseusContextPlugin [](#__codelineno-1-2)from google.adk.agents import Agent [](#__codelineno-1-3)from google.adk.apps import App [](#__codelineno-1-4)from google.adk.runners import Runner [](#__codelineno-1-5)from google.adk.sessions import InMemorySessionService [](#__codelineno-1-6)[](#__codelineno-1-7)agent = Agent(     [](#__codelineno-1-8)    name="assistant",    [](#__codelineno-1-9)    model="gemini-flash-latest",    [](#__codelineno-1-10)    instruction="Help the user.", [](#__codelineno-1-11)) [](#__codelineno-1-12)[](#__codelineno-1-13)app = App(     [](#__codelineno-1-14)    name="perseus_app",    [](#__codelineno-1-15)    root_agent=agent,    [](#__codelineno-1-16)    plugins=[PerseusContextPlugin("context.perseus")], [](#__codelineno-1-17)) [](#__codelineno-1-18)[](#__codelineno-1-19)runner = Runner(     [](#__codelineno-1-20)    app=app,    [](#__codelineno-1-21)    session_service=InMemorySessionService(), [](#__codelineno-1-22))`

### Single agent (callback)[¶](#single-agent-callback "Permanent link")

`[](#__codelineno-2-1)from adk_perseus_context import perseus_before_model_callback [](#__codelineno-2-2)from google.adk.agents import Agent [](#__codelineno-2-3)[](#__codelineno-2-4)agent = Agent(     [](#__codelineno-2-5)    name="assistant",    [](#__codelineno-2-6)    model="gemini-flash-latest",    [](#__codelineno-2-7)    instruction="Help the user.",    [](#__codelineno-2-8)    before_model_callback=perseus_before_model_callback("context.perseus"), [](#__codelineno-2-9))`

Either way, the compiled context is appended to the request's system instruction (via ADK's `LlmRequest.append_instructions`) on every model call. If Perseus is unavailable or a compile fails, the request proceeds without injected context and a warning is logged (`fail_open=True` by default).

### Per-session context[¶](#per-session-context "Permanent link")

Override the source per session through session state. This is useful when each user or task targets a different workspace or directive set. Create the session inside an async function:

`[](#__codelineno-3-1)session = await runner.session_service.create_session(     [](#__codelineno-3-2)    app_name="perseus_app",    [](#__codelineno-3-3)    user_id="user",    [](#__codelineno-3-4)    state={        [](#__codelineno-3-5)        "_perseus_source": "@perseus\n@file AGENTS.md\n@memory deployment",        [](#__codelineno-3-6)        "_perseus_workspace": "/path/to/project",    [](#__codelineno-3-7)    }, [](#__codelineno-3-8))`

## Use as an MCP server (optional)[¶](#use-as-an-mcp-server-optional "Permanent link")

Perseus also ships an MCP server that exposes its directives as tools, so you can consume it through ADK's `McpToolset` instead of (or alongside) the plugin:

`[](#__codelineno-4-1)from google.adk.agents import Agent [](#__codelineno-4-2)from google.adk.tools.mcp_tool import McpToolset, StdioConnectionParams [](#__codelineno-4-3)from mcp import StdioServerParameters [](#__codelineno-4-4)[](#__codelineno-4-5)perseus_tools = McpToolset(     [](#__codelineno-4-6)    connection_params=StdioConnectionParams(        [](#__codelineno-4-7)        server_params=StdioServerParameters(            [](#__codelineno-4-8)            command="perseus",            [](#__codelineno-4-9)            args=["mcp", "serve", "--workspace", "."],        [](#__codelineno-4-10)        )    [](#__codelineno-4-11)    ) [](#__codelineno-4-12)) [](#__codelineno-4-13)[](#__codelineno-4-14)agent = Agent(     [](#__codelineno-4-15)    name="assistant",    [](#__codelineno-4-16)    model="gemini-flash-latest",    [](#__codelineno-4-17)    instruction="Use Perseus tools to read workspace context.",    [](#__codelineno-4-18)    tools=[perseus_tools], [](#__codelineno-4-19))`

## Plugin reference[¶](#plugin-reference "Permanent link")

Entry point

Scope

Description

`PerseusContextPlugin(source)`

Runner-wide

Injects the compiled context into every agent's model request

`perseus_before_model_callback(source)`

Single agent

A `before_model_callback` that injects the compiled context

`_perseus_source` / `_perseus_workspace`

Session state

Per-session overrides of the source and workspace
