# Cisco AI Defense plugin for ADK[¶](#cisco-ai-defense-plugin-for-adk "Permanent link")

Supported in ADKPython

[Cisco AI Defense](https://www.cisco.com/site/us/en/products/security/ai-defense/index.html) is an enterprise AI security platform that provides runtime guardrails to protect against threats like prompt injection, data leakage, and harmful content. The [ADK plugin](https://github.com/cisco-ai-defense/ai-defense-google-adk) integrates these guardrails directly into the ADK Runner lifecycle: it inspects prompts, model responses, and tool calls, then allows or blocks them based on configurable security policies.

## Use cases[¶](#use-cases "Permanent link")

-   **Runtime protection for model calls**: Inspect user prompts before model calls and model outputs after generation, then allow or block based on policy (`monitor` or `enforce`).
-   **Tool and MCP call inspection**: Inspect tool call requests before execution and tool responses after execution, and block unsafe tool behavior in `enforce` mode with clear metadata.
-   **Auditable decision trace and alerts**: Capture decision context (action, severity, classifications, request\_id/event\_id) and optionally trigger an `on_violation` callback for monitoring and incident response.

## Prerequisites[¶](#prerequisites "Permanent link")

-   [Cisco AI Defense](https://www.cisco.com/site/us/en/products/security/ai-defense/index.html) account and API key
-   Python >= 3.10
-   [ADK](https://adk.dev) >= 1.0.0

## Installation[¶](#installation "Permanent link")

`[](#__codelineno-0-1)pip install cisco-aidefense-google-adk`

Set the `AI_DEFENSE_API_KEY` environment variable (and `AI_DEFENSE_MCP_API_KEY` for tool inspection).

## Use with agent[¶](#use-with-agent "Permanent link")

### Quickstart[¶](#quickstart "Permanent link")

Add Cisco AI Defense to any ADK agent with a single line:

`[](#__codelineno-1-1)from aidefense_google_adk import defend [](#__codelineno-1-2)[](#__codelineno-1-3)agent = defend(agent, mode="enforce")`

Or get a plugin for the entire app:

`[](#__codelineno-2-1)from google.adk.apps import App [](#__codelineno-2-2)[](#__codelineno-2-3)from aidefense_google_adk import defend [](#__codelineno-2-4)[](#__codelineno-2-5)plugin = defend(mode="enforce") [](#__codelineno-2-6)app = App(name="my_app", root_agent=agent, plugins=[plugin])`

### Global plugin[¶](#global-plugin "Permanent link")

Use `CiscoAIDefensePlugin` to apply inspection globally to all agents in a Runner:

`[](#__codelineno-3-1)from google.adk.agents import LlmAgent [](#__codelineno-3-2)from google.adk.apps import App [](#__codelineno-3-3)from google.adk.runners import Runner [](#__codelineno-3-4)from google.adk.sessions import InMemorySessionService [](#__codelineno-3-5)[](#__codelineno-3-6)from aidefense_google_adk import CiscoAIDefensePlugin [](#__codelineno-3-7)[](#__codelineno-3-8)agent = LlmAgent(     [](#__codelineno-3-9)    model="gemini-flash-latest",    [](#__codelineno-3-10)    name="assistant",    [](#__codelineno-3-11)    instruction="You are a helpful assistant.", [](#__codelineno-3-12)) [](#__codelineno-3-13)[](#__codelineno-3-14)app = App(     [](#__codelineno-3-15)    name="my_app",    [](#__codelineno-3-16)    root_agent=agent,    [](#__codelineno-3-17)    plugins=[        [](#__codelineno-3-18)        CiscoAIDefensePlugin(mode="enforce"),    [](#__codelineno-3-19)    ], [](#__codelineno-3-20)) [](#__codelineno-3-21)runner = Runner(app=app, session_service=InMemorySessionService())`

### Per-agent callbacks[¶](#per-agent-callbacks "Permanent link")

Use `make_aidefense_callbacks` to wire inspection into a specific agent:

`[](#__codelineno-4-1)from google.adk.agents import LlmAgent [](#__codelineno-4-2)from aidefense_google_adk import make_aidefense_callbacks [](#__codelineno-4-3)[](#__codelineno-4-4)cbs = make_aidefense_callbacks(mode="enforce") [](#__codelineno-4-5)[](#__codelineno-4-6)agent = LlmAgent(     [](#__codelineno-4-7)    model="gemini-flash-latest",    [](#__codelineno-4-8)    name="assistant",    [](#__codelineno-4-9)    instruction="You are a helpful assistant.", [](#__codelineno-4-10)) [](#__codelineno-4-11)cbs.apply_to(agent)  # wires all 4 callbacks`

## Modes[¶](#modes "Permanent link")

The plugin supports three operating modes:

Mode

Behavior

`monitor`

Inspect all traffic, log violations, never block (default)

`enforce`

Inspect all traffic, block requests/responses that violate policy

`off`

Skip inspection entirely

Modes can be set globally or per-channel:

`[](#__codelineno-5-1)CiscoAIDefensePlugin(     [](#__codelineno-5-2)    mode="monitor",      # default for both    [](#__codelineno-5-3)    llm_mode="enforce",  # override for LLM only    [](#__codelineno-5-4)    mcp_mode="off",      # override for tools only [](#__codelineno-5-5))`

## Violation callback[¶](#violation-callback "Permanent link")

Use the `on_violation` callback to receive notifications for every violation in both `monitor` and `enforce` modes:

`[](#__codelineno-6-1)def handle_violation(result):     [](#__codelineno-6-2)    print(f"Violation: {result.action} / {result.severity}") [](#__codelineno-6-3)[](#__codelineno-6-4)CiscoAIDefensePlugin(     [](#__codelineno-6-5)    mode="monitor",    [](#__codelineno-6-6)    on_violation=handle_violation, [](#__codelineno-6-7))`

## Retry and fail-open support[¶](#retry-and-fail-open-support "Permanent link")

For automatic retry with exponential backoff, fail-open/fail-closed semantics, and structured `Decision` objects, use the `AgentsecPlugin` variant:

`[](#__codelineno-7-1)from google.adk.apps import App [](#__codelineno-7-2)[](#__codelineno-7-3)from aidefense_google_adk import AgentsecPlugin [](#__codelineno-7-4)[](#__codelineno-7-5)app = App(     [](#__codelineno-7-6)    name="my_app",    [](#__codelineno-7-7)    root_agent=agent,    [](#__codelineno-7-8)    plugins=[        [](#__codelineno-7-9)        AgentsecPlugin(            [](#__codelineno-7-10)            mode="enforce",            [](#__codelineno-7-11)            fail_open=True,            [](#__codelineno-7-12)            retry_total=3,            [](#__codelineno-7-13)            retry_backoff=0.5,        [](#__codelineno-7-14)        ),    [](#__codelineno-7-15)    ], [](#__codelineno-7-16))`

Or at the per-agent level:

`[](#__codelineno-8-1)from aidefense_google_adk import make_agentsec_callbacks [](#__codelineno-8-2)[](#__codelineno-8-3)cbs = make_agentsec_callbacks(mode="enforce", fail_open=True) [](#__codelineno-8-4)cbs.apply_to(agent)`
