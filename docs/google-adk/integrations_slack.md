# Slack runner for ADK[¶](#slack-runner-for-adk "Permanent link")

Supported in ADKPython

ADK provides the `SlackRunner` class to allow you to deploy your agents directly on Slack using [Socket Mode](https://api.slack.com/apis/connections/socket). This integration acts as an adapter that handles event listening, response dispatching, and automated conversation thread management.

## Use cases[¶](#use-cases "Permanent link")

-   **Socket Mode deployment**: Route workspace events to your agent without exposing public HTTP endpoints.
-   **Thread management**: Maintain continuous conversation context across direct messages and nested thread replies.
-   **Event-driven triggers**: Activate agent workflows automatically using direct messages or app mentions.

## Prerequisites[¶](#prerequisites "Permanent link")

-   Slack App configured in your [Slack API Dashboard](https://api.slack.com/apps). You must sign in to your Slack account first.
-   Bot User OAuth Token (`xoxb-...`) with `app_mentions:read`, `chat:write`, and `im:history` bot token scopes.
-   Websocket App-Level Token (`xapp-...`) with the `connections:write` scope.

## Installation[¶](#installation "Permanent link")

Run the following command in your terminal to install the ADK along with all necessary Slack Socket Mode dependencies

`[](#__codelineno-0-1)pip install "google-adk[slack]"`

## Use with agent[¶](#use-with-agent "Permanent link")

This example shows you the end-to-end setup for deploying an agent to Slack. It configures a core agent, establishes an in-memory session to manage conversation history, and uses SlackRunner with Socket Mode to connect to your workspace and handle incoming events.

`[](#__codelineno-1-1)import asyncio [](#__codelineno-1-2)import os [](#__codelineno-1-3)from google.adk.agents import Agent [](#__codelineno-1-4)from google.adk.runners import Runner [](#__codelineno-1-5)from google.adk.sessions import InMemorySessionService [](#__codelineno-1-6)from google.adk.integrations.slack import SlackRunner [](#__codelineno-1-7)from slack_bolt.app.async_app import AsyncApp [](#__codelineno-1-8)[](#__codelineno-1-9)# Define the core agent [](#__codelineno-1-10)root_agent = Agent(     [](#__codelineno-1-11)    model="gemini-flash-latest",    [](#__codelineno-1-12)    name="slack_agent",    [](#__codelineno-1-13)    instruction="You are a helpful team assistant running on Slack.", [](#__codelineno-1-14)) [](#__codelineno-1-15)[](#__codelineno-1-16)# Wire it up to Slack over Socket Mode [](#__codelineno-1-17)runner = Runner(     [](#__codelineno-1-18)    app_name="slack_agent",    [](#__codelineno-1-19)    agent=root_agent,    [](#__codelineno-1-20)    session_service=InMemorySessionService(),    [](#__codelineno-1-21)    auto_create_session=True, [](#__codelineno-1-22)) [](#__codelineno-1-23)slack_app = AsyncApp(token=os.environ["SLACK_BOT_TOKEN"]) [](#__codelineno-1-24)slack_runner = SlackRunner(runner, slack_app) [](#__codelineno-1-25)[](#__codelineno-1-26)asyncio.run(slack_runner.start(os.environ["SLACK_APP_TOKEN"]))`
