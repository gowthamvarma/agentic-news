# Synap integration for ADK[¶](#synap-integration-for-adk "Permanent link")

Supported in ADKPython

The [`maximem-synap-google-adk`](https://pypi.org/project/maximem-synap-google-adk/) plugin connects your ADK agent to [Synap](https://www.maximem.ai/synap), a managed long-term memory layer for AI agents. Synap automatically extracts and structures knowledge from conversations (facts, preferences, episodes, emotions, and temporal events) and retrieves only what is semantically relevant to the current query.

## Use cases[¶](#use-cases "Permanent link")

-   **Persistent cross-session memory**: Give your ADK agents long-term memory that survives across sessions and deployments, with no manual bookkeeping.
-   **Multi-tenant isolation**: Memory is scoped to `user_id` and `customer_id`, ensuring strict isolation in multi-user deployments.
-   **Semantic recall**: Server-side extraction surfaces only what is relevant to the current query, keeping prompts short and tokens efficient.

## Prerequisites[¶](#prerequisites "Permanent link")

-   A [Synap](https://synap.maximem.ai) account and API key
-   [Gemini API key](https://aistudio.google.com/app/api-keys) (or any other model provider configured with ADK)

## Installation[¶](#installation "Permanent link")

`[](#__codelineno-0-1)pip install maximem-synap-google-adk maximem-synap`

Set the following environment variable:

`[](#__codelineno-1-1)export SYNAP_API_KEY="your-synap-api-key"`

## Use with agent[¶](#use-with-agent "Permanent link")

`create_synap_tools(...)` returns two `FunctionTool` instances, `search_memory` and `store_memory`, that the agent can call to recall and persist memories on demand.

`[](#__codelineno-2-1)import os [](#__codelineno-2-2)[](#__codelineno-2-3)from google.adk.agents.llm_agent import Agent [](#__codelineno-2-4)from maximem_synap import MaximemSynapSDK [](#__codelineno-2-5)from synap_google_adk import create_synap_tools [](#__codelineno-2-6)[](#__codelineno-2-7)sdk = MaximemSynapSDK(api_key=os.environ["SYNAP_API_KEY"]) [](#__codelineno-2-8)[](#__codelineno-2-9)synap_tools = create_synap_tools(     [](#__codelineno-2-10)    sdk=sdk,    [](#__codelineno-2-11)    user_id="alice",    [](#__codelineno-2-12)    customer_id="acme_corp", [](#__codelineno-2-13)) [](#__codelineno-2-14)[](#__codelineno-2-15)root_agent = Agent(     [](#__codelineno-2-16)    model="gemini-flash-latest",    [](#__codelineno-2-17)    name="memory_assistant",    [](#__codelineno-2-18)    instruction=(        [](#__codelineno-2-19)        "You are a helpful assistant with long-term memory. "        [](#__codelineno-2-20)        "Use search_memory to recall what you know about the user. "        [](#__codelineno-2-21)        "Use store_memory to save important new facts the user mentions."    [](#__codelineno-2-22)    ),    [](#__codelineno-2-23)    tools=synap_tools, [](#__codelineno-2-24))`

Run with:

`[](#__codelineno-3-1)adk run path/to/your_agent`

Teach the agent something on the first turn (e.g. *"I'm allergic to peanuts"*), then ask about it on a later turn. Synap retrieves the relevant memory automatically, even across separate `adk run` invocations.

## Available tools[¶](#available-tools "Permanent link")

Tool

Description

`search_memory`

Semantic search over the user's stored memories. Takes a natural-language query and returns the most relevant facts, preferences, and episodes.

`store_memory`

Persist an explicit fact in the user's long-term memory. The agent calls this when the user shares something worth remembering.
