# Langfuse observability for ADK[¶](#langfuse-observability-for-adk "Permanent link")

Supported in ADKPython

[Langfuse](https://langfuse.com) is an open-source LLM engineering platform for observability, evaluation, and prompt management. It captures detailed traces from ADK agents using the OpenTelemetry (OTel) protocol, so you can debug, evaluate, and iterate on agent apps in development and production.

## Overview[¶](#overview "Permanent link")

Langfuse captures traces from ADK using OpenTelemetry and supports the [AI Engineering Loop](https://langfuse.com/academy/ai-engineering-loop):

-   **[Trace](https://langfuse.com/academy/tracing)**: Capture the full path of a request, including prompts, retrieved context, tool calls, outputs, latency, and cost
-   **[Monitor](https://langfuse.com/academy/monitoring)**: Track how the system behaves over time and surface the traces that deserve attention, using evaluation methods, user feedback, and cost or latency anomalies
-   **[Build datasets](https://langfuse.com/academy/datasets)**: Turn real scenarios from monitoring and expected scenarios from development into repeatable test cases
-   **[Experiment](https://langfuse.com/academy/experiments)**: Change variables systematically (a prompt, a model, a retrieval strategy) and compare each change against a stable baseline
-   **[Evaluate](https://langfuse.com/academy/evaluate)**: Decide whether results are good enough to ship using manual review, code evaluator checks, or LLM-as-a-judge

## Installation[¶](#installation "Permanent link")

Install the required packages:

`[](#__codelineno-0-1)pip install langfuse "google-adk>=2" openinference-instrumentation-google-adk`

`google-adk` 2.x requires Python 3.10 or later. Pinning `"google-adk>=2"` ensures pip installs the current ADK 2.x release.

## Setup[¶](#setup "Permanent link")

Sign up at [cloud.langfuse.com](https://cloud.langfuse.com) or [self-host](https://langfuse.com/self-hosting) the platform, then set your API keys. Get keys from your project settings page. Also set a [Gemini API key](https://aistudio.google.com/app/apikey):

`[](#__codelineno-1-1)export LANGFUSE_PUBLIC_KEY="pk-lf-..." [](#__codelineno-1-2)export LANGFUSE_SECRET_KEY="sk-lf-..." [](#__codelineno-1-3)export LANGFUSE_BASE_URL="https://cloud.langfuse.com"  # EU region [](#__codelineno-1-4)# Other regions: https://us.cloud.langfuse.com (US), [](#__codelineno-1-5)# https://jp.cloud.langfuse.com (Japan), https://hipaa.cloud.langfuse.com (HIPAA) [](#__codelineno-1-6)export GOOGLE_API_KEY="your-gemini-api-key"`

Initialize the Langfuse client and instrument ADK:

`[](#__codelineno-2-1)from langfuse import get_client [](#__codelineno-2-2)from openinference.instrumentation.google_adk import GoogleADKInstrumentor [](#__codelineno-2-3)[](#__codelineno-2-4)langfuse = get_client() [](#__codelineno-2-5)[](#__codelineno-2-6)# Verify connection [](#__codelineno-2-7)if langfuse.auth_check():     [](#__codelineno-2-8)    print("Langfuse client is authenticated and ready!") [](#__codelineno-2-9)else:     [](#__codelineno-2-10)    print("Authentication failed. Please check your credentials and host.") [](#__codelineno-2-11)[](#__codelineno-2-12)GoogleADKInstrumentor().instrument()`

That's it. All ADK agent activity will now be traced and sent to your Langfuse project automatically.

## Observe[¶](#observe "Permanent link")

With tracing initialized, run your ADK agent as usual and all interactions will appear in Langfuse:

`[](#__codelineno-3-1)from google.adk.agents import Agent [](#__codelineno-3-2)from google.adk.runners import Runner [](#__codelineno-3-3)from google.adk.sessions import InMemorySessionService [](#__codelineno-3-4)from google.genai import types [](#__codelineno-3-5)[](#__codelineno-3-6)def say_hello():     [](#__codelineno-3-7)    return {"greeting": "Hello Langfuse 👋"} [](#__codelineno-3-8)[](#__codelineno-3-9)agent = Agent(     [](#__codelineno-3-10)    name="hello_agent",    [](#__codelineno-3-11)    model="gemini-3.5-flash",    [](#__codelineno-3-12)    instruction="Always greet using the say_hello tool.",    [](#__codelineno-3-13)    tools=[say_hello], [](#__codelineno-3-14)) [](#__codelineno-3-15)[](#__codelineno-3-16)APP_NAME = "hello_app" [](#__codelineno-3-17)USER_ID = "demo-user" [](#__codelineno-3-18)SESSION_ID = "demo-session" [](#__codelineno-3-19)[](#__codelineno-3-20)session_service = InMemorySessionService() [](#__codelineno-3-21)# create_session is async → await it in notebooks [](#__codelineno-3-22)await session_service.create_session(app_name=APP_NAME, user_id=USER_ID, session_id=SESSION_ID) [](#__codelineno-3-23)[](#__codelineno-3-24)runner = Runner(agent=agent, app_name=APP_NAME, session_service=session_service) [](#__codelineno-3-25)[](#__codelineno-3-26)user_msg = types.Content(role="user", parts=[types.Part(text="hi")]) [](#__codelineno-3-27)for event in runner.run(user_id=USER_ID, session_id=SESSION_ID, new_message=user_msg):     [](#__codelineno-3-28)    if event.is_final_response():        [](#__codelineno-3-29)        if event.content and event.content.parts:            [](#__codelineno-3-30)            print(event.content.parts[0].text)        [](#__codelineno-3-31)        elif event.error_message:            [](#__codelineno-3-32)            print(f"Agent error: {event.error_message}")`

Langfuse automatically maps the `user_id` and `session_id` you pass to `runner.run()` to the trace's **user** and **session** — you get [user](https://langfuse.com/docs/observability/features/users) and [session](https://langfuse.com/docs/observability/features/sessions) tracking without any extra code.

## Named and filterable traces[¶](#named-and-filterable-traces "Permanent link")

By default, traces are named after the ADK app. Use [`propagate_attributes`](https://langfuse.com/docs/observability/sdk/instrumentation) to set a descriptive trace name, tags, and metadata so you can filter traces in Langfuse.

Use the async `runner.run_async()` API when setting attributes this way. The synchronous `runner.run()` executes the agent on a background worker thread, so OpenTelemetry context (and attributes from `propagate_attributes`) does not reach the ADK spans:

`[](#__codelineno-4-1)from langfuse import propagate_attributes [](#__codelineno-4-2)[](#__codelineno-4-3)SESSION_ID_2 = "demo-session-2" [](#__codelineno-4-4)await session_service.create_session(app_name=APP_NAME, user_id=USER_ID, session_id=SESSION_ID_2) [](#__codelineno-4-5)[](#__codelineno-4-6)with propagate_attributes(     [](#__codelineno-4-7)    trace_name="hello-agent-request",    [](#__codelineno-4-8)    tags=["google-adk", "cookbook"],    [](#__codelineno-4-9)    metadata={"example": "named-trace"}, [](#__codelineno-4-10)):     [](#__codelineno-4-11)    async for event in runner.run_async(user_id=USER_ID, session_id=SESSION_ID_2, new_message=user_msg):        [](#__codelineno-4-12)        if event.is_final_response():            [](#__codelineno-4-13)            if event.content and event.content.parts:                [](#__codelineno-4-14)                print(event.content.parts[0].text)            [](#__codelineno-4-15)            elif event.error_message:                [](#__codelineno-4-16)                print(f"Agent error: {event.error_message}")`

## View traces in Langfuse[¶](#view-traces-in-langfuse "Permanent link")

Open your **Langfuse dashboard → Traces** to inspect agent loops, tool calls, and model generations. Traces are filterable by the users, sessions, and tags set above.

![Google ADK example trace in Langfuse](./images/img_bb6886efef.png)

For multi-agent pipelines, scoring traces with user feedback, and more examples, see the [Langfuse ADK integration guide](https://langfuse.com/integrations/frameworks/google-adk).
