# Gemini API Computer Use tool for ADK[¶](#gemini-api-computer-use-tool-for-adk "Permanent link")

Supported in ADKPython v1.17.0Preview

The Computer Use Toolset allows an agent to operate a user interface of a computer, such as browsers, to complete tasks. This tool uses a specific Gemini model and the [Playwright](https://playwright.dev/) testing tool to control a Chromium browser and can interact with web pages by taking screenshots, clicking, typing, and navigating.

For more information about the computer use model, see Gemini API [Computer use](https://ai.google.dev/gemini-api/docs/computer-use) or the Agent Platform API [Computer use](https://cloud.google.com/vertex-ai/generative-ai/docs/computer-use).

Preview release

The Computer Use model and tool is a Preview release. For more information, see the [launch stage descriptions](https://cloud.google.com/products#product-launch-stages).

## Setup[¶](#setup "Permanent link")

You must install Playwright and its dependencies, including Chromium, to be able to use the Computer Use Toolset.

Recommended: create and activate a Python virtual environment

Create a Python virtual environment:

`[](#__codelineno-0-1)python3 -m venv .venv`

Activate the Python virtual environment:

Windows CMDWindows PowershellMacOS / Linux

`[](#__codelineno-1-1).venv\Scripts\activate.bat`

`[](#__codelineno-2-1).venv\Scripts\Activate.ps1`

`[](#__codelineno-3-1)source .venv/bin/activate`

To set up the required software libraries for the Computer Use Toolset:

1.  Install Python dependencies:
    
    `[](#__codelineno-4-1)pip install termcolor==3.1.0 [](#__codelineno-4-2)pip install playwright==1.52.0 [](#__codelineno-4-3)pip install browserbase==1.3.0 [](#__codelineno-4-4)pip install rich`
    
2.  Install the Playwright dependencies, including the Chromium browser:
    
    `[](#__codelineno-5-1)playwright install-deps chromium [](#__codelineno-5-2)playwright install chromium`
    

## Use the tool[¶](#use-the-tool "Permanent link")

Use the Computer Use Toolset by adding it as a tool to your agent. When you configure the tool, you must provide a implementation of the `BaseComputer` class which defines an interface for an agent to use a computer. In the following example, the `PlaywrightComputer` class is defined for this purpose. You can find the code for this implementation in `playwright.py` file of the [computer\_use](https://github.com/google/adk-python/blob/main/contributing/samples/multimodal/computer_use/playwright.py) agent sample project.

`[](#__codelineno-6-1)from google.adk import Agent [](#__codelineno-6-2)from google.adk.tools.computer_use.computer_use_toolset import ComputerUseToolset [](#__codelineno-6-3)[](#__codelineno-6-4)from .playwright import PlaywrightComputer [](#__codelineno-6-5)[](#__codelineno-6-6)root_agent = Agent(     [](#__codelineno-6-7)    model='gemini-2.5-computer-use-preview-10-2025',    [](#__codelineno-6-8)    name='hello_world_agent',    [](#__codelineno-6-9)    description=(        [](#__codelineno-6-10)        'computer use agent that can operate a browser on a computer to finish'        [](#__codelineno-6-11)        ' user tasks'    [](#__codelineno-6-12)    ),    [](#__codelineno-6-13)    instruction='you are a computer use agent',    [](#__codelineno-6-14)    tools=[        [](#__codelineno-6-15)        ComputerUseToolset(computer=PlaywrightComputer(screen_size=(1280, 936)))    [](#__codelineno-6-16)    ], [](#__codelineno-6-17))`

For a complete code example, see the [computer\_use](https://github.com/google/adk-python/tree/main/contributing/samples/multimodal/computer_use) agent sample project.
