# Files Retrieval tool for ADK[¶](#files-retrieval-tool-for-adk "Permanent link")

Supported in ADKPython

The `FilesRetrieval` tool lets your ADK agent index and query local documents using retrieval-augmented generation (RAG). It builds a LlamaIndex `VectorStoreIndex` over a directory you specify, using Google's Gemini embedding model. Your agent can then retrieve relevant excerpts from local text files, Markdown documents, and source files to ground its answers in project-specific context.

## Use cases[¶](#use-cases "Permanent link")

-   **Codebase and Documentation Search**: Retrieve relevant functions, design notes and documentation from a local repository to answer technical questions.
-   **Local Knowledge Base Grounding**: Index internal markdown files, technical specifications, and guides straight from your own filesystem, without first loading them into a hosted document store. Document content is sent to the configured embedding model for indexing, so review the data handling terms for Google AI Studio or Agent Platform before indexing sensitive material.
-   **Context-Augmented Assistance**: Retrieve relevant domain-specific data from reports, logs, or text files to ground agent responses in verified source material.

## Prerequisites[¶](#prerequisites "Permanent link")

The `FilesRetrieval` tool indexes documents with LlamaIndex, which ADK does not install by default. Install the extra that provides it:

`[](#__codelineno-0-1)pip install "google-adk[extensions]"`

Then configure credentials for either Google AI Studio or Agent Platform:

Google AI StudioAgent Platform

Generate an API key in [Google AI Studio](https://aistudio.google.com/) and set the environment variable:

`[](#__codelineno-1-1)export GOOGLE_API_KEY="your-api-key"`

Configure Agent Platform access with your Google Cloud credentials:

`[](#__codelineno-2-1)export GOOGLE_GENAI_USE_ENTERPRISE=TRUE [](#__codelineno-2-2)export GOOGLE_CLOUD_PROJECT="your-project-id" [](#__codelineno-2-3)export GOOGLE_CLOUD_LOCATION="<global | us | eu>"`

Note

For production, pass the GA model explicitly with `embedding_model=GoogleGenAIEmbedding(model_name="gemini-embedding-2", embed_batch_size=1)`. For more information, see [Gemini Embedding](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/embedding-2). For more information on connecting your ADK agent to Google Cloud resources and services, see the Google Cloud [Connection Guide](/get-started/google-cloud/).

## Use with agent[¶](#use-with-agent "Permanent link")

This example configures `FilesRetrieval` for a local data directory and attaches it to an ADK agent. Before running it, create a `data/` directory next to your agent module and add the `.txt` or `.md` files you want indexed: `FilesRetrieval` loads and embeds the entire directory when it is constructed, so the directory must already exist, and the content is re-indexed each time the agent module is imported.

Use this tool when the user asks questions about"        [](#__codelineno-3-14)        " architecture, project structure, or tools."    [](#__codelineno-3-15)    ),    [](#__codelineno-3-16)    input_dir=DATA_DIR, [](#__codelineno-3-17)) [](#__codelineno-3-18)[](#__codelineno-3-19)# Create an agent equipped with the retrieval tool [](#__codelineno-3-20)root_agent = Agent(     [](#__codelineno-3-21)    model="gemini-flash-latest",    [](#__codelineno-3-22)    name="files_retrieval_agent",    [](#__codelineno-3-23)    instruction=(        [](#__codelineno-3-24)        "You are a helpful assistant that answers questions based on local"        [](#__codelineno-3-25)        " documentation files. Always use the search_documents tool to retrieve"        [](#__codelineno-3-26)        " relevant context before generating your answer." ## Available tools[¶](#available-tools "Permanent link")

The `FilesRetrieval` class is a tool. Once attached with `tools=[...]`, the agent sees one function, which takes a single `query` string parameter:

Tool

Description

`search_documents`

Performs semantic vector search over documents in the indexed directory and returns the most relevant content chunk for a given natural language query. Rename it with the `name` parameter.

## Configuration[¶](#configuration "Permanent link")

The `FilesRetrieval` constructor accepts the following parameters:

Parameter

Type

Required

Default

Description

`name`

`str`

**Yes**

—

Unique identifier for the tool, used by the model for function calling.

`description`

`str`

**Yes**

—

Explanation of when and how the agent should invoke the retrieval tool.

`input_dir`

`str`

**Yes**

—

Local filesystem directory path containing the documents to load and index.

`embedding_model`

`Optional[BaseEmbedding]`

No

`None`

Custom LlamaIndex `BaseEmbedding` instance. When omitted, defaults to `GoogleGenAIEmbedding(model_name="gemini-embedding-2-preview", embed_batch_size=1)`.

### Custom embedding models[¶](#custom-embedding-models "Permanent link")

You can customize the embedding model by passing an instance conforming to LlamaIndex's `BaseEmbedding` interface:

`[](#__codelineno-4-1)from google.adk.tools.retrieval.files_retrieval import FilesRetrieval [](#__codelineno-4-2)from llama_index.embeddings.google_genai import GoogleGenAIEmbedding [](#__codelineno-4-3)[](#__codelineno-4-4)custom_embedding = GoogleGenAIEmbedding(     [](#__codelineno-4-5)    model_name="gemini-embedding-2",    [](#__codelineno-4-6)    embed_batch_size=1, [](#__codelineno-4-7)) [](#__codelineno-4-8)[](#__codelineno-4-9)files_retrieval = FilesRetrieval(     [](#__codelineno-4-10)    name="search_documents",    [](#__codelineno-4-11)    description="Search local knowledge base files.",    [](#__codelineno-4-12)    input_dir=os.path.join(os.path.dirname(__file__), "data"),    [](#__codelineno-4-13)    embedding_model=custom_embedding, [](#__codelineno-4-14))`
