# Quickstart: Exposing a remote agent via A2A[¶](#quickstart-exposing-a-remote-agent-via-a2a "Permanent link")

Supported in ADKGoExperimental

This quickstart covers the most common starting point for any developer: **"I have an agent. How do I expose it so that other agents can use my agent via A2A?"**. This is crucial for building complex multi-agent systems where different agents need to collaborate and interact.

## Overview[¶](#overview "Permanent link")

This sample demonstrates how you can easily expose an ADK agent so that it can be then consumed by another agent using the A2A Protocol.

In Go, you expose an agent by using the A2A launcher, which dynamically generates an agent card for you.

`[](#__codelineno-0-1)┌─────────────────┐                             ┌───────────────────────────────┐ [](#__codelineno-0-2)│   Root Agent    │       A2A Protocol          │ A2A-Exposed Check Prime Agent │ [](#__codelineno-0-3)│                 │────────────────────────────▶│      (localhost: 8001)        │ [](#__codelineno-0-4)└─────────────────┘                             └───────────────────────────────┘`

The sample consists of :

-   **Remote Prime Agent** (`remote_a2a/check_prime_agent/main.go`): This is the agent that you want to expose so that other agents can use it via A2A. It is an agent that handles prime number checking. It becomes exposed using the A2A launcher.
-   **Root Agent** (`main.go`): A simple agent that is just calling the remote prime agent.

## Exposing the Remote Agent with the A2A Launcher[¶](#exposing-the-remote-agent-with-the-a2a-launcher "Permanent link")

You can take an existing agent built using the Go ADK and make it A2A-compatible by using the A2A launcher.

### 1\. Getting the Sample Code[¶](#getting-the-sample-code "Permanent link")

First, make sure you have Go installed and your environment is set up.

You can clone and navigate to the [**`a2a_basic`** sample](https://github.com/google/adk-docs/tree/main/examples/go/a2a_basic) here:

`[](#__codelineno-1-1)cd examples/go/a2a_basic`

As you'll see, the folder structure is as follows:

`[](#__codelineno-2-1)a2a_basic/ [](#__codelineno-2-2)├── remote_a2a/ [](#__codelineno-2-3)│   └── check_prime_agent/ [](#__codelineno-2-4)│       └── main.go    # Remote Prime Agent [](#__codelineno-2-5)├── go.mod [](#__codelineno-2-6)├── go.sum [](#__codelineno-2-7)└── main.go            # Root agent`

#### Root Agent (`a2a_basic/main.go`)[¶](#root-agent-a2a_basicmaingo "Permanent link")

-   **`newRootAgent`**: A local agent that connects to the remote A2A service.

#### Remote Prime Agent (`a2a_basic/remote_a2a/check_prime_agent/main.go`)[¶](#remote-prime-agent-a2a_basicremote_a2acheck_prime_agentmaingo "Permanent link")

-   **`checkPrimeTool`**: Function for prime number checking.
-   **`main`**: The main function that creates the agent and starts the A2A server.

### 2\. Start the Remote A2A Agent server[¶](#start-the-remote-a2a-agent-server "Permanent link")

You can now start the remote agent server, which will host the `check_prime_agent`:

`[](#__codelineno-3-1)# Start the remote agent [](#__codelineno-3-2)go run remote_a2a/check_prime_agent/main.go`

Once executed, you should see something like:

`[](#__codelineno-4-1)2025/11/06 11:00:19 Starting A2A prime checker server on port 8001 [](#__codelineno-4-2)2025/11/06 11:00:19 Starting the web server: &{port:8001} [](#__codelineno-4-3)2025/11/06 11:00:19  [](#__codelineno-4-4)2025/11/06 11:00:19 Web servers starts on http://localhost:8001 [](#__codelineno-4-5)2025/11/06 11:00:19        a2a:  you can access A2A using jsonrpc protocol: http://localhost:8001`

### 3\. Check that your remote agent is running[¶](#check-that-your-remote-agent-is-running "Permanent link")

You can check that your agent is up and running by visiting the agent card that was auto-generated by the A2A launcher:

[http://localhost:8001/.well-known/agent-card.json](http://localhost:8001/.well-known/agent-card.json)

You should see the contents of the agent card.

### 4\. Run the Main (Consuming) Agent[¶](#run-the-main-consuming-agent "Permanent link")

Now that your remote agent is running, you can run the main agent.

`[](#__codelineno-5-1)# In a separate terminal, run the main agent [](#__codelineno-5-2)go run main.go`

#### How it works[¶](#how-it-works "Permanent link")

The remote agent is exposed using the A2A launcher in the `main` function. The launcher takes care of starting the server and generating the agent card.

remote\_a2a/check\_prime\_agent/main.go

``[](#__codelineno-6-1)func main() {     [](#__codelineno-6-2)    ctx := context.Background()    [](#__codelineno-6-3)    primeTool, err := functiontool.New(functiontool.Config{        [](#__codelineno-6-4)        Name:        "prime_checking",        [](#__codelineno-6-5)        Description: "Check if numbers in a list are prime using efficient mathematical algorithms",    [](#__codelineno-6-6)    }, checkPrimeTool)    [](#__codelineno-6-7)    if err != nil {        [](#__codelineno-6-8)        log.Fatalf("Failed to create prime_checking tool: %v", err)    [](#__codelineno-6-9)    } [](#__codelineno-6-10)    [](#__codelineno-6-11)    model, err := gemini.NewModel(ctx, "gemini-2.0-flash", &genai.ClientConfig{})    [](#__codelineno-6-12)    if err != nil {        [](#__codelineno-6-13)        log.Fatalf("Failed to create model: %v", err)    [](#__codelineno-6-14)    } [](#__codelineno-6-15)    [](#__codelineno-6-16)    primeAgent, err := llmagent.New(llmagent.Config{        [](#__codelineno-6-17)        Name:        "check_prime_agent",        [](#__codelineno-6-18)        Description: "check prime agent that can check whether numbers are prime.",        [](#__codelineno-6-19)        Instruction: `            [](#__codelineno-6-20)            You check whether numbers are prime.            [](#__codelineno-6-21)            When checking prime numbers, call the check_prime tool with a list of integers. Be sure to pass in a list of integers. You should never pass in a string.            [](#__codelineno-6-22)            You should not rely on the previous history on prime results.    [](#__codelineno-6-23)    `,        [](#__codelineno-6-24)        Model: model,        [](#__codelineno-6-25)        Tools: []tool.Tool{primeTool},    [](#__codelineno-6-26)    })    [](#__codelineno-6-27)    if err != nil {        [](#__codelineno-6-28)        log.Fatalf("Failed to create agent: %v", err)    [](#__codelineno-6-29)    } [](#__codelineno-6-30)    [](#__codelineno-6-31)    // Create launcher. The a2a.NewLauncher() will dynamically generate the agent card.    [](#__codelineno-6-32)    port := 8001    [](#__codelineno-6-33)    webLauncher := web.NewLauncher(a2a.NewLauncher())    [](#__codelineno-6-34)    _, err = webLauncher.Parse([]string{        [](#__codelineno-6-35)        "--port", strconv.Itoa(port),        [](#__codelineno-6-36)        "a2a", "--a2a_agent_url", "http://localhost:" + strconv.Itoa(port),    [](#__codelineno-6-37)    })    [](#__codelineno-6-38)    if err != nil {        [](#__codelineno-6-39)        log.Fatalf("launcher.Parse() error = %v", err)    [](#__codelineno-6-40)    } [](#__codelineno-6-41)    [](#__codelineno-6-42)    // Create ADK config    [](#__codelineno-6-43)    config := &launcher.Config{        [](#__codelineno-6-44)        AgentLoader:    agent.NewSingleLoader(primeAgent),        [](#__codelineno-6-45)        SessionService: session.InMemoryService(),    [](#__codelineno-6-46)    } [](#__codelineno-6-47)    [](#__codelineno-6-48)    log.Printf("Starting A2A prime checker server on port %d\n", port)    [](#__codelineno-6-49)    // Run launcher    [](#__codelineno-6-50)    if err := webLauncher.Run(context.Background(), config); err != nil {        [](#__codelineno-6-51)        log.Fatalf("webLauncher.Run() error = %v", err)    [](#__codelineno-6-52)    } [](#__codelineno-6-53)}``
