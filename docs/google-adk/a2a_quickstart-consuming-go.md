# Quickstart: Consuming a remote agent via A2A[¶](#quickstart-consuming-a-remote-agent-via-a2a "Permanent link")

Supported in ADKGoExperimental

This quickstart covers the most common starting point for any developer: **"There is a remote agent, how do I let my ADK agent use it via A2A?"**. This is crucial for building complex multi-agent systems where different agents need to collaborate and interact.

## Overview[¶](#overview "Permanent link")

This sample demonstrates the **Agent2Agent (A2A)** architecture in the Agent Development Kit (ADK), showcasing how multiple agents can work together to handle complex tasks. The sample implements an agent that can roll dice and check if numbers are prime.

`[](#__codelineno-0-1)┌─────────────────┐    ┌──────────────────┐    ┌────────────────────┐ [](#__codelineno-0-2)│   Root Agent    │───▶│   Roll Agent     │    │   Remote Prime     │ [](#__codelineno-0-3)│  (Local)        │    │   (Local)        │    │   Agent            │ [](#__codelineno-0-4)│                 │    │                  │    │  (localhost:8001)  │ [](#__codelineno-0-5)│                 │───▶│                  │◀───│                    │ [](#__codelineno-0-6)└─────────────────┘    └──────────────────┘    └────────────────────┘`

The A2A Basic sample consists of:

-   **Root Agent** (`root_agent`): The main orchestrator that delegates tasks to specialized sub-agents
-   **Roll Agent** (`roll_agent`): A local sub-agent that handles dice rolling operations
-   **Prime Agent** (`prime_agent`): A remote A2A agent that checks if numbers are prime, this agent is running on a separate A2A server

## Exposing Your Agent with the ADK Server[¶](#exposing-your-agent-with-the-adk-server "Permanent link")

In the `a2a_basic` example, you will first need to expose the `check_prime_agent` via an A2A server, so that the local root agent can use it.

### 1\. Getting the Sample Code[¶](#getting-the-sample-code "Permanent link")

First, make sure you have Go installed and your environment is set up.

You can clone and navigate to the [**`a2a_basic`** sample](https://github.com/google/adk-docs/tree/main/examples/go/a2a_basic) here:

`[](#__codelineno-1-1)cd examples/go/a2a_basic`

As you'll see, the folder structure is as follows:

`[](#__codelineno-2-1)a2a_basic/ [](#__codelineno-2-2)├── remote_a2a/ [](#__codelineno-2-3)│   └── check_prime_agent/ [](#__codelineno-2-4)│       └── main.go [](#__codelineno-2-5)├── go.mod [](#__codelineno-2-6)├── go.sum [](#__codelineno-2-7)└── main.go # local root agent`

#### Main Agent (`a2a_basic/main.go`)[¶](#main-agent-a2a_basicmaingo "Permanent link")

-   **`rollDieTool`**: Function tool for rolling dice
-   **`newRollAgent`**: Local agent specialized in dice rolling
-   **`newPrimeAgent`**: Remote A2A agent configuration
-   **`newRootAgent`**: Main orchestrator with delegation logic

#### Remote Prime Agent (`a2a_basic/remote_a2a/check_prime_agent/main.go`)[¶](#remote-prime-agent-a2a_basicremote_a2acheck_prime_agentmaingo "Permanent link")

-   **`checkPrimeTool`**: Prime number checking algorithm
-   **`main`**: Implementation of the prime checking service and A2A server.

### 2\. Start the Remote Prime Agent server[¶](#start-the-remote-prime-agent-server "Permanent link")

To show how your ADK agent can consume a remote agent via A2A, you'll first need to start a remote agent server, which will host the prime agent (under `check_prime_agent`).

`[](#__codelineno-3-1)# Start the remote a2a server that serves the check_prime_agent on port 8001 [](#__codelineno-3-2)go run remote_a2a/check_prime_agent/main.go`

Once executed, you should see something like:

`[](#__codelineno-4-1)2025/11/06 11:00:19 Starting A2A prime checker server on port 8001 [](#__codelineno-4-2)2025/11/06 11:00:19 Starting the web server: &{port:8001} [](#__codelineno-4-3)2025/11/06 11:00:19  [](#__codelineno-4-4)2025/11/06 11:00:19 Web servers starts on http://localhost:8001 [](#__codelineno-4-5)2025/11/06 11:00:19        a2a:  you can access A2A using jsonrpc protocol: http://localhost:8001`

### 3\. Look out for the required agent card of the remote agent[¶](#look-out-for-the-required-agent-card-of-the-remote-agent "Permanent link")

A2A Protocol requires that each agent must have an agent card that describes what it does.

In the Go ADK, the agent card is generated dynamically when you expose an agent using the A2A launcher. You can visit `http://localhost:8001/.well-known/agent-card.json` to see the generated card.

### 4\. Run the Main (Consuming) Agent[¶](#run-the-main-consuming-agent "Permanent link")

`[](#__codelineno-5-1)# In a separate terminal, run the main agent [](#__codelineno-5-2)go run main.go`

#### How it works[¶](#how-it-works "Permanent link")

The main agent uses `remoteagent.New` to consume the remote agent (`prime_agent` in our example). As you can see below, it requires the `Name`, `Description`, and the `AgentCardSource` URL.

a2a\_basic/main.go

`[](#__codelineno-6-1)func newPrimeAgent() (agent.Agent, error) {     [](#__codelineno-6-2)    remoteAgent, err := remoteagent.NewA2A(remoteagent.A2AConfig{        [](#__codelineno-6-3)        Name:            "prime_agent",        [](#__codelineno-6-4)        Description:     "Agent that handles checking if numbers are prime.",        [](#__codelineno-6-5)        AgentCardSource: "http://localhost:8001",    [](#__codelineno-6-6)    })    [](#__codelineno-6-7)    if err != nil {        [](#__codelineno-6-8)        return nil, fmt.Errorf("failed to create remote prime agent: %w", err)    [](#__codelineno-6-9)    }    [](#__codelineno-6-10)    return remoteAgent, nil [](#__codelineno-6-11)}`

Then, you can simply use the remote agent in your root agent. In this case, `primeAgent` is used as one of the sub-agents in the `root_agent` below:

a2a\_basic/main.go

``[](#__codelineno-7-1)func newRootAgent(ctx context.Context, rollAgent, primeAgent agent.Agent) (agent.Agent, error) {     [](#__codelineno-7-2)    model, err := gemini.NewModel(ctx, "gemini-2.0-flash", &genai.ClientConfig{})    [](#__codelineno-7-3)    if err != nil {        [](#__codelineno-7-4)        return nil, err    [](#__codelineno-7-5)    }    [](#__codelineno-7-6)    return llmagent.New(llmagent.Config{        [](#__codelineno-7-7)        Name:  "root_agent",        [](#__codelineno-7-8)        Model: model,        [](#__codelineno-7-9)        Instruction: `      [](#__codelineno-7-10)      You are a helpful assistant that can roll dice and check if numbers are prime.      [](#__codelineno-7-11)      You delegate rolling dice tasks to the roll_agent and prime checking tasks to the prime_agent.      [](#__codelineno-7-12)      Follow these steps:      [](#__codelineno-7-13)      1. If the user asks to roll a die, delegate to the roll_agent.      [](#__codelineno-7-14)      2. If the user asks to check primes, delegate to the prime_agent.      [](#__codelineno-7-15)      3. If the user asks to roll a die and then check if the result is prime, call roll_agent first, then pass the result to prime_agent.      [](#__codelineno-7-16)      Always clarify the results before proceeding.    [](#__codelineno-7-17)    `,        [](#__codelineno-7-18)        SubAgents: []agent.Agent{rollAgent, primeAgent},        [](#__codelineno-7-19)        Tools:     []tool.Tool{},    [](#__codelineno-7-20)    }) [](#__codelineno-7-21)}``

## Example Interactions[¶](#example-interactions "Permanent link")

Once both your main and remote agents are running, you can interact with the root agent to see how it calls the remote agent via A2A:

**Simple Dice Rolling:** This interaction uses a local agent, the Roll Agent:

`[](#__codelineno-8-1)User: Roll a 6-sided die [](#__codelineno-8-2)Bot calls tool: transfer_to_agent with args: map[agent_name:roll_agent] [](#__codelineno-8-3)Bot calls tool: roll_die with args: map[sides:6] [](#__codelineno-8-4)Bot: I rolled a 6-sided die and the result is 6.`

**Prime Number Checking:**

This interaction uses a remote agent via A2A, the Prime Agent:

`[](#__codelineno-9-1)User: Is 7 a prime number? [](#__codelineno-9-2)Bot calls tool: transfer_to_agent with args: map[agent_name:prime_agent] [](#__codelineno-9-3)Bot calls tool: prime_checking with args: map[nums:[7]] [](#__codelineno-9-4)Bot: Yes, 7 is a prime number.`

**Combined Operations:**

This interaction uses both the local Roll Agent and the remote Prime Agent:

`[](#__codelineno-10-1)User: roll a die and check if it's a prime [](#__codelineno-10-2)Bot: Okay, I will first roll a die and then check if the result is a prime number. [](#__codelineno-10-3)[](#__codelineno-10-4)Bot calls tool: transfer_to_agent with args: map[agent_name:roll_agent] [](#__codelineno-10-5)Bot calls tool: roll_die with args: map[sides:6] [](#__codelineno-10-6)Bot calls tool: transfer_to_agent with args: map[agent_name:prime_agent] [](#__codelineno-10-7)Bot calls tool: prime_checking with args: map[nums:[3]] [](#__codelineno-10-8)Bot: 3 is a prime number.`
