# Apigee API Hub tool for ADK[¶](#apigee-api-hub-tool-for-adk "Permanent link")

Supported in ADKPython v0.1.0

**ApiHubToolset** lets you turn any documented API from Apigee API hub into a tool with a few lines of code. This section shows you the step-by-step instructions including setting up authentication for a secure connection to your APIs.

**Prerequisites**

1.  [Install ADK](/get-started/installation/)
2.  Install the [Google Cloud CLI](https://cloud.google.com/sdk/docs/install?db=bigtable-docs#installation_instructions).
3.  [Apigee API hub](https://cloud.google.com/apigee/docs/apihub/what-is-api-hub) instance with documented (i.e. OpenAPI spec) APIs
4.  Set up your project structure and create required files

``[](#__codelineno-0-1)project_root_folder  [](#__codelineno-0-2) | [](#__codelineno-0-3) `-- my_agent     [](#__codelineno-0-4)     |-- .env     [](#__codelineno-0-5)     |-- __init__.py     [](#__codelineno-0-6)     |-- agent.py     [](#__codelineno-0-7)     `__ tool.py``

## Create an API Hub Toolset[¶](#create-an-api-hub-toolset "Permanent link")

Note: This tutorial includes an agent creation. If you already have an agent, you only need to follow a subset of these steps.

1.  Get your access token, so that APIHubToolset can fetch spec from API Hub API. In your terminal run the following command
    
    `[](#__codelineno-1-1)gcloud auth print-access-token [](#__codelineno-1-2)# Prints your access token like 'ya29....'`
    
2.  Ensure that the account used has the required permissions. You can use the pre-defined role `roles/apihub.viewer` or assign the following permissions:
    
    1.  **apihub.specs.get (required)**
    2.  apihub.apis.get (optional)
    3.  apihub.apis.list (optional)
    4.  apihub.versions.get (optional)
    5.  apihub.versions.list (optional)
    6.  apihub.specs.list (optional)
3.  Create a tool with `APIHubToolset`. Add the below to `tools.py`
    
    If your API requires authentication, you must configure authentication for the tool. The following code sample demonstrates how to configure an API key. ADK supports token based auth (API Key, Bearer token), service account, and OpenID Connect. We will soon add support for various OAuth2 flows.
    
    `[](#__codelineno-2-1)from google.adk.tools.openapi_tool.auth.auth_helpers import token_to_scheme_credential [](#__codelineno-2-2)from google.adk.tools.apihub_tool.apihub_toolset import APIHubToolset [](#__codelineno-2-3)[](#__codelineno-2-4)# Provide authentication for your APIs. Not required if your APIs don't required authentication. [](#__codelineno-2-5)auth_scheme, auth_credential = token_to_scheme_credential(     [](#__codelineno-2-6)    "apikey", "query", "apikey", apikey_credential_str [](#__codelineno-2-7)) [](#__codelineno-2-8)[](#__codelineno-2-9)sample_toolset = APIHubToolset(     [](#__codelineno-2-10)    name="apihub-sample-tool",    [](#__codelineno-2-11)    description="Sample Tool",    [](#__codelineno-2-12)    access_token="...",  # Copy your access token generated in step 1    [](#__codelineno-2-13)    apihub_resource_name="...", # API Hub resource name    [](#__codelineno-2-14)    auth_scheme=auth_scheme,    [](#__codelineno-2-15)    auth_credential=auth_credential, [](#__codelineno-2-16))`
    
    For production deployment we recommend using a service account instead of an access token. In the code snippet above, use `service_account_json=service_account_cred_json_str` and provide your security account credentials instead of the token.
    
    For apihub\_resource\_name, if you know the specific ID of the OpenAPI Spec being used for your API, use `` `projects/my-project-id/locations/us-west1/apis/my-api-id/versions/version-id/specs/spec-id` ``. If you would like the Toolset to automatically pull the first available spec from the API, use `` `projects/my-project-id/locations/us-west1/apis/my-api-id` ``
    
4.  Create your agent file Agent.py and add the created tools to your agent definition:
    
    `[](#__codelineno-3-1)from google.adk.agents.llm_agent import LlmAgent [](#__codelineno-3-2)from .tools import sample_toolset [](#__codelineno-3-3)[](#__codelineno-3-4)root_agent = LlmAgent(     [](#__codelineno-3-5)    model='gemini-flash-latest',    [](#__codelineno-3-6)    name='enterprise_assistant',    [](#__codelineno-3-7)    instruction='Help user, leverage the tools you have access to',    [](#__codelineno-3-8)    tools=[sample_toolset], [](#__codelineno-3-9))`
    
5.  Configure your `__init__.py` to expose your agent
    
    `[](#__codelineno-4-1)from . import agent`
    
6.  Start the Google ADK Web UI and try your agent:
    
    ``[](#__codelineno-5-1)# make sure to run `adk web` from your project_root_folder [](#__codelineno-5-2)adk web``
    

Then go to [http://localhost:8000](http://localhost:8000) to try your agent from the Web UI.
