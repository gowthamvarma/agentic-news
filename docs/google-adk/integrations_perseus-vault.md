# Perseus Vault Memory integration for ADK[¶](#perseus-vault-memory-integration-for-adk "Permanent link")

Supported in ADKPython

The [`adk-perseus-vault-memory`](https://github.com/Perseus-Computing-LLC/adk-mimir-memory) integration connects your ADK agent to Perseus Vault, a persistent, cross-session memory backend. Backed by a single Rust binary with an embedded SQLite database, it requires **zero cloud dependencies**, and everything runs locally. Memory is encrypted at rest with AES-256-GCM, and search combines FTS5 keyword matching with dense vector retrieval.

## Use cases[¶](#use-cases "Permanent link")

-   **Persistent agent memory across restarts**: Sessions survive process restarts, and agents recall past conversations automatically
-   **Private, air-gapped deployments**: No cloud dependency, and Perseus Vault runs entirely on your machine with optional AES-256-GCM encryption
-   **Hybrid search across memories**: Combine keyword (FTS5/BM25) and semantic (dense vector) search to find relevant past interactions
-   **Workspace-aware agents**: Pair with Perseus for agents that know about your project files, git state, and configuration

## Prerequisites[¶](#prerequisites "Permanent link")

-   Python 3.10+
-   The `perseus-vault` binary already installed. See [Perseus Computing Vault](https://perseus.observer/vault/) for availability and instructions.
-   `google-adk>=1.0.0`

## Use with agent[¶](#use-with-agent "Permanent link")

Create the `PerseusVaultMemoryService`, pass it to your `Runner`, and give the agent the `load_memory` tool so it can recall past sessions:

`[](#__codelineno-0-1)from adk_perseus_vault_memory import PerseusVaultMemoryService [](#__codelineno-0-2)from google.adk.agents import Agent [](#__codelineno-0-3)from google.adk.runners import Runner [](#__codelineno-0-4)from google.adk.sessions import InMemorySessionService [](#__codelineno-0-5)from google.adk.tools import load_memory [](#__codelineno-0-6)[](#__codelineno-0-7)agent = Agent(     [](#__codelineno-0-8)    name="memory_assistant",    [](#__codelineno-0-9)    model="gemini-flash-latest",    [](#__codelineno-0-10)    instruction="You are a helpful assistant with long-term memory.",    [](#__codelineno-0-11)    tools=[load_memory], [](#__codelineno-0-12)) [](#__codelineno-0-13)[](#__codelineno-0-14)runner = Runner(     [](#__codelineno-0-15)    agent=agent,    [](#__codelineno-0-16)    app_name="perseus_vault_app",    [](#__codelineno-0-17)    session_service=InMemorySessionService(),    [](#__codelineno-0-18)    memory_service=PerseusVaultMemoryService(db_path="~/.adk/vault.db"), [](#__codelineno-0-19))`

After a session completes, call `await memory_service.add_session_to_memory(session)` to persist it; the agent recalls memories in later sessions through the `load_memory` tool. See [ADK memory](/sessions/memory/) for the full ingest-and-recall flow.

### Perseus live context (optional)[¶](#perseus-live-context-optional "Permanent link")

For live workspace awareness, install the `perseus` extra:

`[](#__codelineno-1-1)pip install adk-perseus-vault-memory[perseus]`

Then use the prebuilt `perseus_context_agent`, which resolves `@file`, `@search`, and `@memory` directives at inference time:

`[](#__codelineno-2-1)from adk_perseus_vault_memory.perseus_context import perseus_context_agent [](#__codelineno-2-2)from google.adk.runners import Runner [](#__codelineno-2-3)from google.adk.sessions import InMemorySessionService [](#__codelineno-2-4)[](#__codelineno-2-5)# The pre-built agent ships without a model; set one before use. [](#__codelineno-2-6)perseus_context_agent.model = "gemini-flash-latest" [](#__codelineno-2-7)[](#__codelineno-2-8)runner = Runner(     [](#__codelineno-2-9)    agent=perseus_context_agent,    [](#__codelineno-2-10)    app_name="perseus_app",    [](#__codelineno-2-11)    session_service=InMemorySessionService(),    [](#__codelineno-2-12)    memory_service=PerseusVaultMemoryService(db_path="~/.adk/vault.db"), [](#__codelineno-2-13))`

Set Perseus directives via session state when creating the session (inside an async function):

`[](#__codelineno-3-1)session = await runner.session_service.create_session(     [](#__codelineno-3-2)    app_name="perseus_app",    [](#__codelineno-3-3)    user_id="user",    [](#__codelineno-3-4)    state={        [](#__codelineno-3-5)        "_perseus_directives": "@file AGENTS.md @file README.md @memory deployment",        [](#__codelineno-3-6)        "_perseus_workspace": "/path/to/project",    [](#__codelineno-3-7)    }, [](#__codelineno-3-8))`

## Available memory operations[¶](#available-memory-operations "Permanent link")

Method

Description

`add_session_to_memory(session)`

Persist a full session's events

`add_events_to_memory(...)`

Append incremental event deltas

`add_memory(...)`

Store explicit memory entries

`search_memory(...)`

FTS5 keyword search across memories
