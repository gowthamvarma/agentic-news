# BigQuery tool for ADK[¶](#bigquery-tool-for-adk "Permanent link")

Supported in ADKPython v1.1.0

These are a set of tools aimed to provide integration with BigQuery, namely:

-   **`list_dataset_ids`**: Fetches BigQuery dataset ids present in a GCP project.
-   **`get_dataset_info`**: Fetches metadata about a BigQuery dataset.
-   **`list_table_ids`**: Fetches table ids present in a BigQuery dataset.
-   **`get_table_info`**: Fetches metadata about a BigQuery table.
-   **`get_job_info`**: Fetches metadata information about a BigQuery job (slot usage, configuration, statistics, status, etc.).
-   **`execute_sql`**: Runs a SQL query in BigQuery and fetch the result.
-   **`forecast`**: Runs a BigQuery AI time series forecast using the `AI.FORECAST` function.
-   **`analyze_contribution`**: Performs BigQuery ML contribution analysis to understand what drives changes in a metric.
-   **`detect_anomalies`**: Trains an ARIMA\_PLUS model and detects anomalies in time series data.
-   **`ask_data_insights`**: Answers questions about data in BigQuery tables using natural language.
-   **`search_catalog`**: Finds BigQuery datasets and tables using natural language semantic search via Dataplex.

They are packaged in the toolset `BigQueryToolset`.

## Authentication[¶](#authentication "Permanent link")

The `BigQueryToolset` supports several authentication mechanisms through `BigQueryCredentialsConfig`.

### Application Default Credentials[¶](#application-default-credentials "Permanent link")

You should use this approach for local development and running on Google Cloud services, such as Cloud Run and GKE.

`[](#__codelineno-0-1)import google.auth [](#__codelineno-0-2)from google.adk.integrations.bigquery import BigQueryToolset, BigQueryCredentialsConfig [](#__codelineno-0-3)[](#__codelineno-0-4)# Load Application Default Credentials [](#__codelineno-0-5)credentials, project_id = google.auth.default() [](#__codelineno-0-6)[](#__codelineno-0-7)# Configure the toolset [](#__codelineno-0-8)credentials_config = BigQueryCredentialsConfig(credentials=credentials) [](#__codelineno-0-9)bigquery_toolset = BigQueryToolset(credentials_config=credentials_config)`

### Service Account[¶](#service-account "Permanent link")

You can explicitly provide a service account file or info.

`[](#__codelineno-1-1)from google.oauth2 import service_account [](#__codelineno-1-2)from google.adk.integrations.bigquery import BigQueryToolset, BigQueryCredentialsConfig [](#__codelineno-1-3)[](#__codelineno-1-4)# Load Service Account credentials [](#__codelineno-1-5)credentials = service_account.Credentials.from_service_account_file('path/to/key.json') [](#__codelineno-1-6)[](#__codelineno-1-7)# Configure the toolset [](#__codelineno-1-8)credentials_config = BigQueryCredentialsConfig(credentials=credentials) [](#__codelineno-1-9)bigquery_toolset = BigQueryToolset(credentials_config=credentials_config)`

### External Access Token[¶](#external-access-token "Permanent link")

For applications that need to act on behalf of an end-user, you can pass user credentials directly instantiated from an access token, such as from an OAuth2 flow or an external IDP.

`[](#__codelineno-2-1)from google.oauth2.credentials import Credentials [](#__codelineno-2-2)from google.adk.integrations.bigquery import BigQueryToolset, BigQueryCredentialsConfig [](#__codelineno-2-3)[](#__codelineno-2-4)# Assume 'user_token' is obtained via an external OAuth flow [](#__codelineno-2-5)credentials = Credentials(token=user_token) [](#__codelineno-2-6)[](#__codelineno-2-7)# Configure the toolset [](#__codelineno-2-8)credentials_config = BigQueryCredentialsConfig(credentials=credentials) [](#__codelineno-2-9)bigquery_toolset = BigQueryToolset(credentials_config=credentials_config)`

### External Auth Providers[¶](#external-auth-providers "Permanent link")

If you are integrating with an external authentication provider where the token is managed by the platform, such as Gemini Enterprise, use `external_access_token_key`.

`[](#__codelineno-3-1)from google.adk.integrations.bigquery import BigQueryToolset, BigQueryCredentialsConfig [](#__codelineno-3-2)[](#__codelineno-3-3)# The key used to look up the access token in the session state [](#__codelineno-3-4)credentials_config = BigQueryCredentialsConfig(     [](#__codelineno-3-5)    external_access_token_key="YOUR_AUTH_ID" [](#__codelineno-3-6)) [](#__codelineno-3-7)bigquery_toolset = BigQueryToolset(credentials_config=credentials_config)`

### Interactive Auth (ADK Web)[¶](#interactive-auth-adk-web "Permanent link")

When using the `adk web` interface for interactive sessions, you can provide OAuth 2.0 client credentials to trigger a login flow. This mechanism works for both local development and when your ADK agent is deployed to environments like Cloud Run.

`[](#__codelineno-4-1)from google.adk.integrations.bigquery import BigQueryToolset, BigQueryCredentialsConfig [](#__codelineno-4-2)[](#__codelineno-4-3)# Provide OAuth 2.0 Client ID and Secret [](#__codelineno-4-4)credentials_config = BigQueryCredentialsConfig(     [](#__codelineno-4-5)    client_id="YOUR_CLIENT_ID",    [](#__codelineno-4-6)    client_secret="YOUR_CLIENT_SECRET" [](#__codelineno-4-7)) [](#__codelineno-4-8)bigquery_toolset = BigQueryToolset(credentials_config=credentials_config)`
